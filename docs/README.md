# Demo_CarProfile documentation site (docs/)

This folder is designed for GitHub Pages static hosting.

## Enable GitHub Pages
GitHub Repo → Settings → Pages:
- Source: Deploy from a branch
- Branch: main
- Folder: /docs

## Optional: add the demo GIF
The repository includes `demo.gif`. To display it on the Pages site:
- copy it to: `docs/assets/demo.gif`

Then commit and push.
